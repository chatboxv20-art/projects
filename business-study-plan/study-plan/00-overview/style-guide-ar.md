# دليل الأسلوب — شكل الدروس في المشروع ده

الملف ده هو **عقد الجودة** اللي كل درس في المشروع ده لازم يلتزم بيه حرف بحرف. الأسلوب مأخوذ من ملف المواصفات `prompt.md`، ومطبّق على كل الدروس.

---

## 1. قاعدة اللغة (أهم قاعدة في المشروع كله)

كل درس **ثنائي اللغة بفصل بلوكات كامل**:

1. كل قسم بيتكتب **بالكامل بالإنجليزي الأول** (كل جملة وكل نقطة والسؤال كله).
2. وبعده مباشرة لافتة `**Egyptian Arabic (اللهجة المصرية):**` وبعدين **نفس القسم كامل بالعامية المصرية الطبيعية**.
3. **ممنوع** الخلط سطر بسطر أو نقطة بنقطة بين اللغتين جوه نفس القسم.
4. كل بلوك لغة لازم يقف لوحده: لو شيلت بلوك، التاني يفضل مفهوم وكامل لوحده.

### العناوين
نص العنوان ممكن يحمل الترجمة العربية بين قوسين (مثال: `Why It Matters (ليه مهم)`)، وده الإنجليزي الوحيد المسموح على سطر العنوان نفسه. المحتوى بيتكتب تحته كبلوكين منفصلين.

### اللهجة
المقصود بالعامية المصرية هو **الشارع المصري الحقيقي** — مش الفصحى، ومش أسلوب الجرايد الجاف.

### الحاجات اللي ما بتتترجمش

| النوع | مثال |
|---|---|
| اللينكات والـ URLs | `https://www.ifrs.org/` |
| حقول المصادر: Resource Name / Type / Link / Difficulty / Estimated Time | `OpenStax` / `Open Textbook` / `Beginner` / `25 hours` |
| الكود وأوامر التيرمنال | `=NPV(10%, B2:B5)` |
| أسماء المقررات وأكوادها | `ACC101`, `FIN202` |
| رؤوس الجداول وبنية الجدول | نفس الجدول يتكرر إنجليزي وعربي |

## 2. قاعدة التعريف الأول

كل موضوع لازم يفتح **مباشرة تحت العنوان** ببلوك التعريف ده:

```
Topic Name (اسم الموضوع بالعربي)
English Definition: <تعريف كامل بالإنجليزي>
Egyptian Arabic Definition: <نفس التعريف بالعامية المصرية>
```
مافيش أي كلام بين العنوان وبلوك التعريف.

---

## 3. الترتيب داخل كل موضوع

بعد التعريف، كل بند بيتكتب ببلوكين (إنجليزي كامل ثم عربي كامل):

1. What It Is — يعني إيه
2. Why It Exists — ليه موجود
3. Why It Matters — ليه مهم
4. Where It Is Used — بنستخدمه فين
5. Real-World Usage and Relevance — الاستخدام والملاءمة في المجال
6. Advantages — المميزات
7. Limitations — الحدود
8. Best Practices — أحسن الممارسات
9. Common Mistakes — الأخطاء الشائعة

---

## 4. التعلّم العملي (بعد كل موضوع)

- Practical Example — مثال عملي
- Hands-On Exercise — تمرين عملي بإيدك
- Practice Questions — أسئلة تدريب
- Quiz — اختبار قصير
- Quiz Answers — إجابات الاختبار
- Homework — الواجب
- Revision Notes — ملاحظات مراجعة

---

## 5. المصادر الدراسية (إجبارية في كل درس)

كل درس فيه **بالظبط**: مصدر أساسي واحد، ومصدر اختياري واحد، ومنصة تمرين واحدة. ولكل مصدر: Resource Name / Type / Direct Link / Difficulty / Estimated Time (زي ما هم)، و Why Recommended و What to Study From It (بالبلوكين).

ترتيب الأولويات: الدوكيومنتيشن الرسمي، ثم منصات التعليم الكبيرة، ثم منصات التمرين، ثم قنوات يوتيوب محترمة.

---

## 6. نهاية كل درس — البلوكات الإجبارية

الترتيب ده بالظبط، وكلها ببلوكين:

1. Lesson Summary — ملخص الدرس
2. Key Takeaways — أهم النقط
3. Common Mistakes — الأخطاء الشائعة
4. Quiz — الاختبار
5. Quiz Answers — إجابات الاختبار
6. Practice Exercise — تمرين عملي
7. Homework — الواجب
8. Recommended Revision — المراجعة الموصى بيها
9. Preview of the Next Lesson — نظرة على الدرس الجاي
10. Important Terms — مصطلحات مهمة

### قاعدة "المصطلحات المهمة"

دي **مصطلحات مساعدة** ظهرت في الشرح، مش موضوع الدرس الأساسي اللي اتعرف فوق أصلاً.

---

## 7. تشيك ليست المراجعة الذاتية قبل التسليم

- [ ] كل قسم فيه بلوك إنجليزي كامل وبلوك عربي كامل تحته؟
- [ ] كل بلوك إنجليزي إنجليزي 100%، وكل بلوك عربي عامية مصرية 100%، ومافيش خلط؟
- [ ] اللينكات وحقول المصادر والكود والجداول اتسابت زي ما هي؟
- [ ] كل موضوع بيفتح ببلوك التعريف بتاعه مباشرة تحت العنوان؟
- [ ] الهيكل مطابق للمقررات، ومافيش حاجة مخترعة؟
